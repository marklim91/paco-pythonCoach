📝 오프라인 로컬 메모 테스트

네트워크를 Offline으로 전환하고 새로고침(F5)해도 페이지와 메모가 그대로 유지됩니다.

    🆔 Manifest id 속성 포인트

    manifest.json에 고유 id를 지정하면 추후 start_url이 변경되어도 동일 앱으로 업데이트됩니다.

    {
  "id": "./",
  "start_url": "./index.html",
  "display": "standalone"
}
