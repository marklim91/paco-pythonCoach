기존 /api/* 호출을 이 브라우저가 대신 처리합니다. 설정은 이 브라우저의 localStorage에만 저장되며 Git에 포함되지 않습니다.

1. 데이터 소스

POST로 { school, studentId, studentName }을 보내고 { "verified": true|false }를 받습니다. 요청 형식이 text/plain이면 흐름에서 json(triggerBody())로 본문을 읽어야 합니다.

브라우저가 응답을 읽으려면 흐름의 Response 동작 헤더에 Access-Control-Allow-Origin(예: 이 주소의 origin)이 필요합니다. 어렵다면 아래 JSON 가져오기를 사용하세요.

흐름의 “행 나열” 결과({ "value": [ … ] } 또는 배열)를 저장한 파일입니다. URL이 비어 있을 때 사용됩니다.
